QuickEye 自動化眼圖分析工具

快速載入 S 參數並自動化執行高速訊號完整性眼圖分析

1. 系統需求與環境安裝

在使用本自動化工具前，請確認您的電腦已安裝 Ansys Electronics Desktop (AEDT)，並需要透過 Python 安裝以下控制依賴套件：

  • 打開命令提示字元 (cmd) 或 PowerShell，輸入以下指令安裝 PyAEDT：

    pip install pyaedt

註：圖形化介面使用了 Tkinter，這通常已經預先包含在標準的 Python 系統環境中，無需另外安裝。

2. 操作步驟說明

  1. 啟動介面： 透過 Python 執行 QuickEye_Analyzer.py 來開啟圖形化操作介面。
  2. 選擇 AEDT 版本： 透過下拉選單選擇您電腦中已安裝的 AEDT 軟體版本 (例如 2026.1)。
  3. 載入 S 參數： 點擊「瀏覽...」選取您的通道模型 (.s2p 或是 .s4p)。
  4. 選擇訊號模式：
    • 差動 (Differential)： 使用 .s4p 檔案，預設 Port 1, 2 為輸入，Port 3, 4 為輸出。
    • 單端 (Single-Ended)： 使用 .s2p 檔案，預設 Port 1 為輸入，Port 2 為輸出。
  5. 設定參數： 輸入傳輸速度 (Gbps) 與串接的級數，介面會自動為您推算出對應的 UI 寬度與合理的上升/下降時間 (20% UI)。
  6. 指定輸出資料夾： 設定分析完成後的專案儲存位置，腳本將自動產生附有時間戳記的 .aedt 與眼圖結果 .jpg 檔案以防覆蓋。
  7. 執行分析： 點選最下方的按鈕，工具便會在背景默默為您完成自動化建模、接線與模擬運算！
